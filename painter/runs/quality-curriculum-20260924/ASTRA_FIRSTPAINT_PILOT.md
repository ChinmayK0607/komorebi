# Astra first-paint SFT pilot, prelaunch record

**Hypothesis.** One exposure of each of 39 distinct visually reviewed Astra first paints, mixed nearly 1:1 with distinct procedural examples, can improve initial painting quality over the public photo-SFT step-512 adapter without repeating the prior 16-scene, three-repeat SFT regression. This is a small diagnostic, not a claim that 39 paintings are enough to solve the project.

**Matched baseline.** The same 28-photo frozen evaluation will run with the step-512 initializer and with the 20-update adapter. First-turn appearance, recognizability and validity are the primary comparison because only the first-paint prompt is supervised. Second-turn outcomes remain visible but are not evidence of trained revision skill. Pairwise visual review uses the reference and both renderings, with failures and censored infrastructure cases retained.

The node package records the full source commit and hashes every included file.

**Schedule.** Fresh optimizer from the step-512 adapter; 80 training rows in 20 updates at effective batch 4, microbatch 1, sequence length 16,384, learning rate 1e-6, checkpoint and validation every 10 updates. 39 first paints, 41 procedural examples, no repeats. The 21 Astra revision examples are held out until their full prior-program state matches the live prompt. Exact Prime processor length and assistant-loss-mask audit must pass on the Linux node before the first update. The Codex Cloud CPU approximation could not run because its package proxy returned HTTP 403 while installing Transformers; this was an infrastructure failure before sample processing.

**Outcome rule.** Do not promote the step-20 checkpoint on training loss or renderer validity alone. Review all 28 matched first-turn pairs; record visual preferences, legibility, program validity and censored renderer cases. If first-turn results regress, retain the initializer and repair the data/scaffold before scaling. If they improve, expand distinct-scene data and then separately test history-aligned revision SFT. Record training/eval wall time, paid-node cost and sampled GPU busy fraction with denominator before release.
