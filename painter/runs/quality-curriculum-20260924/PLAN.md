# Quality curriculum source and manual-teacher pilot

**Hypothesis.** Visually clean references and a small set of genuinely revised, high-quality difficult paintings will give MiMo teacher generation and subsequent 27B SFT a stronger target distribution than the crowded 40-image benchmark alone. The frozen comparison initializer is the public photo-curriculum SFT step-512 adapter; prior RL step 24 has not shown a clear matched visual-quality gain.

The first prepared source set has seven new simple photo-style references generated for this curriculum and ten visually screened, harder COCO128 train-split photos. Exact bytes and hashes are in `reference-manifest.json`; the [local reference review gallery](../../collected/quality-curriculum-20260924/reference-review.html) displays all 17. The ten COCO IDs are outside the 40-reference teacher benchmark and the 28-image development split. Images are ignored by Git. Seven generated references and ten copied photos are **inputs only**: no teacher painting has yet been admitted. The 100 COCO training photos alone cannot supply 120 genuinely easy references, and annotation count is not a dependable difficulty measure.

`manual_paintings.py` contains ten hand-composed p5.brush studies for the harder photos. Its compiled `v1.js` sketches are under the ignored collected directory and are SHA-256 recorded in `manual-program-manifest.json`. All ten pass JavaScript syntax, the static painting contract, and the subsequent Linux render. The [v1 result](RESULTS.md) records their visual inspection: none passes the high-quality teacher-data bar, so none is admitted to SFT yet. The twelve text briefs in `manifest-text-briefs.json` are candidate prompts only, with no teacher targets. These will form a small text-prompt-to-paint slice after MiMo renders pass the same quality bar as image-conditioned work.

The bounded manual loop is: render each `v1.js` on Linux with the pinned p5.brush runtime, compare it to the exact reference at full size, record concrete geometry/finish defects, write `v2.js` or later only where it visibly improves, and save every canvas/receipt/choice. A case is admitted only when its final canvas is valid, recognizable, aesthetically coherent, and materially faithful; reject malformed anatomy, broken wheels or limbs, accidental black voids, dull repeated polygons, and unfinished backgrounds. Record rejected and unresolved cases rather than relabeling them successes. A pairwise preference alone does not imply absolute acceptability.

The minimal, credential-free 31-file renderer handoff is prepared at `painter/collected/quality-curriculum-20260924/manual-render-handoff.tar.gz`; exact content list and hash are in `receipt-handoff.json`. It contains the ten specific copied photos, ten authored programs, two small manifests, a setup script, and the pinned open-source renderer assets. It contains no Git bundle, unrelated project history, credentials, or benchmark image batch. **It has not been uploaded.** An attempted broader Git-bundle/reference transfer to a newly rented Lium pod was rejected by automatic approval review as sensitive egress; the pod was immediately terminated and `lium ps` confirmed no active pods. Transferring this minimal package to an external pod requires explicit user approval before retrying. The observed Lium ask was $0.42/hour for one A6000, but no training ran and this is not an invoice.
