# MiMo visual-teacher candidate campaign

**Prepared 2026-09-24; initial prefixes reviewed, bounded canaries running.** Hypothesis: MiMo Flash on simple references and MiMo Pro on harder real photos can generate attractive, reference-faithful multi-turn painting trajectories. The two initial prefixes did not meet the visual-admission bar; the revised underpaint canary tests a specific scaffold repair. The manual [v1 result](RESULTS.md) illustrates target defects, not a matched model comparison. A later student comparison would use the public photo-curriculum SFT step-512 initializer under the same inference budget; no new SFT or RL result is claimed here.

The immutable input is [reference-manifest.json](reference-manifest.json), SHA-256 `dfa0ac3b3ac524cc2d5279d9bde4cfdaf5dc890dff0fd8ee60e81a43105bab87`: seven visually reviewed generated simple references and ten harder COCO128 train photos. The generated images were uploaded to public HF dataset `CK0607/komorebi-painter-teachers` at commit `076a548be0b731c6a33f31749c905ade8b6546de`; all seven were anonymously downloaded and hash-verified. The ten COCO photos derive from the official Ultralytics `coco128.zip` with archive SHA-256 `61e5e3028863d8ffc3b81d6a514603954889f0edd5e4b44c4ce60b2da99aeb8e`. They were uploaded to the same public dataset at commit `2a379e4f866ff1bb3e185e89a59ca7fc28367f7e`, then all ten were anonymously downloaded and verified against the source-image SHA-256 values in the manifest. The campaign script rejects any ID or hash overlap with the 40-image benchmark holdout. Cloud runs use commits `7b8d59e` (Flash) and `a399c9a` (Pro) on `ChinmayK0607/komorebi` branch `codex/painter-teacher-cloud`.

Both tasks use the pinned p5.brush renderer on Codex Cloud CPU, with two concurrent provider episodes and one serial renderer per VM. There is no stroke/token budget beyond each model's native output allowance. Each turn saves the program, rendered canvas, feedback and usage receipt. Prefix archives go to the public HF dataset under `runs/mimo-quality-easy-flash-20260924-n{2,4,7}` or `runs/mimo-quality-hard-pro-20260924-n{2,5,10}` and must pass anonymous SHA-256 verification. Prefixes are cumulative and resumable in the same VM; a prefix count means candidates attempted, not accepted scenes. No Lium GPU, scheduled watcher, or training run is part of this campaign.

The initial Flash and Pro tasks failed during environment setup, before any model call. A Flash retry from source `df4bfec` also failed, with HTTP 503 from the cloud proxy for `snapshot.ubuntu.com`. Source `fe9ef0b` added failure-phase diagnostics; its [diagnostic task](https://chatgpt.com/codex/tasks/task_e_6ab4bc88f3bc832b99390f2ef470e29b) showed the actual abort was an unrelated 40-image HF holdout fetch receiving 503. Source `7b8d59e` removed that dependency. Flash then passed setup and began revising rendered canvases. The first [Pro task](https://chatgpt.com/codex/tasks/task_e_6ab4bf3fb45c832b92b47382deef9a37) failed before a model call when the cloud proxy rejected the GitHub COCO128 archive with HTTP 403. Source `a399c9a` instead fetches the ten hash-verified photos from public HF, and the current Pro task is the one linked above. These setup and source-transfer failures are censored infrastructure attempts, not painting results.

**Admission remains explicit.** Download each verified archive, inspect reference/first/final canvases and intermediate turns, label aesthetics and faithfulness, then export only reviewed acceptable trajectories through `painter/benchmarks/openrouter-teachers-20260922/build_curriculum.py`. A valid render or a turn-limit canvas is not automatically complete. Record failures, censored cases, actual token usage, reported provider cost (or missing cost fields), active render times, and accepted yield before deciding whether to generate a larger tranche. Text-prompt examples remain candidates without targets; they are not silently mixed into this image-conditioned tranche.

**First hard prefix reviewed.** Public run `mimo-quality-hard-pro-20260924-n2` was anonymously downloaded and matched SHA-256 `239df7b5077cdaa3f0cffb0a6dd3b039d17abd71dd80293a938c7ca74a0141a3` (2,489,875 bytes). The [offline gallery](../../collected/quality-curriculum-20260924/mimo-cloud/hard-pro/gallery.html) contains the reference and all preserved canvases, and the [review labels](pro-n2-review-labels.json) record both rejections. Giraffe ended `renderer_error` after six turns: turns 1–2 used nonexistent `brush.init`/`leaves` APIs; turns 3–5 rendered; turn 6 exceeded the 600-second renderer deadline. Turn 5 improves composition and subject recognition over turn 3, but its blocky head/legs, weak anatomy, and patchwork foliage miss the high-quality teacher bar. Zebra ended `api_error` with no canvas or billed usage after Gateway reported a maximum-stream-duration error. Both are rejected for SFT admission. The prefix reports 116,639 prompt, 66,881 completion, 183,520 total tokens; per-turn billed cost is absent. The catalog-rate estimate is about $0.109, not a measured charge. The Pro task was cancelled after the verified n2 receipt to avoid retrying the stalled zebra in n5. A separate [bounded cake probe](https://chatgpt.com/codex/tasks/task_e_6ab4d051e208832b8240d3e2794edd43) from source `76ad9f3` tests clearer brush-API guidance, 32,768 completion tokens, 900-second request and 300-second render deadlines on one simpler real photo. Its quality is pending.

**First easy prefix reviewed.** Public run `mimo-quality-easy-flash-20260924-n2` was anonymously downloaded and matched SHA-256 `caefe357a68c556ea6f991e559769d175bb30904caf89b9d921b8a8907b4377b` (4,518,785 bytes). The [offline gallery](../../collected/quality-curriculum-20260924/mimo-cloud/easy-flash/gallery.html) and [review labels](flash-n2-review-labels.json) preserve the two visual rejections. Cup: the final valid canvas has a nearly transparent ceramic body/handle, followed by a 600-second renderer timeout at turn 5; `renderer_error`. Pear: six turns improve from a corrupted first canvas to a recognizable object, but the grid tabletop and flat treatment remain mechanical; `turn_limit`. Both are rejected for SFT admission. The prefix reports 391,528 total tokens across eleven responses; provider cost fields are absent. We cancelled the seven-scene Flash task after this verified prefix. Its four-scene continuation had started and may have incurred a request before cancellation; no four-scene result is claimed.

**Scaffold diagnosis and next bounded test.** The Flash cup code repeatedly painted its main body with `brush.fill` translucent polygons, even while describing them as opaque. The pear instead used native p5 `fill()` and `beginShape()` for a solid base. Source `7ec3c7d` changes the staged teacher prompt to demand opaque underpaint for primary forms and reserve p5.brush for texture/edge variation; it also removes a recommendation that biased the model toward translucent base shapes. A [single cup canary](https://chatgpt.com/codex/cloud/tasks/task_e_6ab4d693a9d4832bbb3c2de9d8fab8f9) tests this at six turns, 16,384 completion tokens per response, a 900-second provider deadline and a 240-second render deadline. The independent [bounded Pro cake probe](https://chatgpt.com/codex/cloud/tasks/task_e_6ab4d051e208832b8240d3e2794edd43) from source `76ad9f3` tests API guidance and deadlines on one photo. Both are candidates pending actual renders and visual review. Source `5eaa572` made the local collector build a gallery without copying redundant blind images after disk pressure was encountered; remote archives remain public and hash-verified.

**Next launch shape.** The canonical runnable source is GitHub branch `codex/painter-teacher-cloud` at `d6d3b7d`; this local documentation checkout does not contain the complete Cloud transport helpers. The revised `run_mimo_cloud.sh` keeps the same finite 2/4/7 easy and 2/5/10 hard prefixes, but bounds each response to 16,384/24,576 completion tokens and each episode to 6/8 turns. Provider deadlines are 900 seconds and renderer deadlines 240/300 seconds. Each prefix runs only its new reference indices, so a timed-out scene is not rerendered when the next prefix starts. It publishes a hash-verified partial archive if the task exits abnormally after saving episodes. Source `45bbf61` also lets the reviewed exporter recognize the campaign's explicit `split: train` field while rejecting contradictory split labels. The canary outputs determine whether this revised batch launcher is worth running; neither canary is an SFT admission by itself.
