# MiMo visual-teacher candidate campaign

**Prepared 2026-09-24; cloud bootstrap recovery in progress.** Hypothesis: MiMo Flash on simple references and MiMo Pro on harder real photos will generate more attractive, reference-faithful multi-turn painting trajectories than the ten hand-authored v1 studies. The manual [v1 result](RESULTS.md) is an illustration of the target defects, not a matched model comparison. The later student comparison remains the public photo-curriculum SFT step-512 initializer under the same inference budget; no new SFT or RL result is claimed here.

The immutable input is [reference-manifest.json](reference-manifest.json), SHA-256 `dfa0ac3b3ac524cc2d5279d9bde4cfdaf5dc890dff0fd8ee60e81a43105bab87`: seven visually reviewed generated simple references and ten harder COCO128 train photos. The generated images were uploaded to public HF dataset `CK0607/komorebi-painter-teachers` at commit `076a548be0b731c6a33f31749c905ade8b6546de`; all seven were anonymously downloaded and hash-verified. The ten COCO photos are fetched on the cloud VM from the official Ultralytics `coco128.zip` with archive SHA-256 `61e5e3028863d8ffc3b81d6a514603954889f0edd5e4b44c4ce60b2da99aeb8e`, then compared with each source-image SHA-256. The campaign script also rejects any ID or hash overlap with the 40-image benchmark holdout. The cloud source commit is `c8c39ba` on `ChinmayK0607/komorebi` branch `codex/painter-teacher-cloud`.

Both tasks use the pinned p5.brush renderer on Codex Cloud CPU, with two concurrent provider episodes and one serial renderer per VM. There is no stroke/token budget beyond each model's native output allowance. Each turn saves the program, rendered canvas, feedback and usage receipt. Prefix archives go to the public HF dataset under `runs/mimo-quality-easy-flash-20260924-n{2,4,7}` or `runs/mimo-quality-hard-pro-20260924-n{2,5,10}` and must pass anonymous SHA-256 verification. Prefixes are cumulative and resumable in the same VM; a prefix count means candidates attempted, not accepted scenes. No Lium GPU, scheduled watcher, or training run is part of this campaign.
