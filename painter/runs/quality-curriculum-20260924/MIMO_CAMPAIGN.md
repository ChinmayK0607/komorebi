# MiMo visual-teacher candidate campaign

**Updated 2026-09-25; initial prefixes, two bounded probes, and the matched Pro cup canary reviewed.** Hypothesis: MiMo Flash on simple references and MiMo Pro on harder real photos can generate attractive, reference-faithful multi-turn painting trajectories. The initial prefixes and both completed bounded probes did not meet the visual-admission bar; the Pro cup canary tested the revised opaque-underpaint scaffold on the same easy reference where Flash failed and also produced no valid final cup. The manual [v1 result](RESULTS.md) illustrates target defects, not a matched model comparison. A later student comparison would use the public photo-curriculum SFT step-512 initializer under the same inference budget; no new SFT or RL result is claimed here.

The immutable input is [reference-manifest.json](reference-manifest.json), SHA-256 `dfa0ac3b3ac524cc2d5279d9bde4cfdaf5dc890dff0fd8ee60e81a43105bab87`: seven visually reviewed generated simple references and ten harder COCO128 train photos. The generated images were uploaded to public HF dataset `CK0607/komorebi-painter-teachers` at commit `076a548be0b731c6a33f31749c905ade8b6546de`; all seven were anonymously downloaded and hash-verified. The ten COCO photos derive from the official Ultralytics `coco128.zip` with archive SHA-256 `61e5e3028863d8ffc3b81d6a514603954889f0edd5e4b44c4ce60b2da99aeb8e`. They were uploaded to the same public dataset at commit `2a379e4f866ff1bb3e185e89a59ca7fc28367f7e`, then all ten were anonymously downloaded and verified against the source-image SHA-256 values in the manifest. The campaign script rejects any ID or hash overlap with the 40-image benchmark holdout. Cloud runs use commits `7b8d59e` (Flash) and `a399c9a` (Pro) on `ChinmayK0607/komorebi` branch `codex/painter-teacher-cloud`.

Both tasks use the pinned p5.brush renderer on Codex Cloud CPU, with two concurrent provider episodes and one serial renderer per VM. There is no stroke/token budget beyond each model's native output allowance. Each turn saves the program, rendered canvas, feedback and usage receipt. Prefix archives go to the public HF dataset under `runs/mimo-quality-easy-flash-20260924-n{2,4,7}` or `runs/mimo-quality-hard-pro-20260924-n{2,5,10}` and must pass anonymous SHA-256 verification. Prefixes are cumulative and resumable in the same VM; a prefix count means candidates attempted, not accepted scenes. No Lium GPU, scheduled watcher, or training run is part of this campaign.

The initial Flash and Pro tasks failed during environment setup, before any model call. A Flash retry from source `df4bfec` also failed, with HTTP 503 from the cloud proxy for `snapshot.ubuntu.com`. Source `fe9ef0b` added failure-phase diagnostics; its [diagnostic task](https://chatgpt.com/codex/tasks/task_e_6ab4bc88f3bc832b99390f2ef470e29b) showed the actual abort was an unrelated 40-image HF holdout fetch receiving 503. Source `7b8d59e` removed that dependency. Flash then passed setup and began revising rendered canvases. The first [Pro task](https://chatgpt.com/codex/tasks/task_e_6ab4bf3fb45c832b92b47382deef9a37) failed before a model call when the cloud proxy rejected the GitHub COCO128 archive with HTTP 403. Source `a399c9a` instead fetches the ten hash-verified photos from public HF, and the current Pro task is the one linked above. These setup and source-transfer failures are censored infrastructure attempts, not painting results.

**Admission remains explicit.** Download each verified archive, inspect reference/first/final canvases and intermediate turns, label aesthetics and faithfulness, then export only reviewed acceptable trajectories through `painter/benchmarks/openrouter-teachers-20260922/build_curriculum.py`. A valid render or a turn-limit canvas is not automatically complete. Record failures, censored cases, actual token usage, reported provider cost (or missing cost fields), active render times, and accepted yield before deciding whether to generate a larger tranche. Text-prompt examples remain candidates without targets; they are not silently mixed into this image-conditioned tranche.

**Scaffold diagnosis and next bounded test.** The Flash cup code repeatedly painted its main body with `brush.fill` translucent polygons, even while describing them as opaque. The pear instead used native p5 `fill()` and `beginShape()` for a solid base. Source `7ec3c7d` changes the staged teacher prompt to demand opaque underpaint for primary forms and reserve p5.brush for texture/edge variation; it also removes a recommendation that biased the model toward translucent base shapes. A [single cup canary](https://chatgpt.com/codex/cloud/tasks/task_e_6ab4d693a9d4832bbb3c2de9d8fab8f9) tested this at six turns, 16,384 completion tokens per response, a 900-second provider deadline and a 240-second render deadline. The independent [bounded Pro cake probe](https://chatgpt.com/codex/cloud/tasks/task_e_6ab4d051e208832b8240d3e2794edd43) from source `76ad9f3` tested API guidance and deadlines on one photo. **Next launch shape.** The canonical runnable source is GitHub branch `codex/painter-teacher-cloud` at `41da4ba`; this local documentation checkout does not contain the complete Cloud transport helpers. The revised `run_mimo_cloud.sh` keeps the same finite 2/4/7 easy and 2/5/10 hard prefixes, but bounds each response to 16,384/24,576 completion tokens and each episode to 6/8 turns. Provider deadlines are 900 seconds, total episode deadlines 2,400/3,600 seconds, and renderer deadlines 240/300 seconds. It publishes a hash-verified partial archive if the task exits abnormally after saving episodes. Source `45bbf61` also lets the reviewed exporter recognize the campaign's explicit `split: train` field while rejecting contradictory split labels. **Native/brush fill diagnostic.** The final program used 34 `brush.fill()` calls before a p5-native `poly()` helper and no `brush.polygon()` calls. The brush fills therefore did not color those native polygons. A deterministic scratch edit changed exactly the 34 fills to p5 native `fill(r,g,b,alpha)`, producing source SHA-256 `53028557a43e410049c084a6bf3159339ed80ac1468ead522f9d1599f39a215d` and a valid protected CPU render in 0.746 seconds with zero model calls. Its PNG SHA-256 is `24b996767335bc14f518884ebc30cb4319efcca2d38907172aa4141a3f9a9cbc`. Public diagnostic archive `diagnostic-pro-cup-native-fill-20260925` at dataset commit `c6e129e1d66bcd1754795dde0ed7b8ea35d7ef23` is 65,088 bytes, SHA-256 `88f0e4f739019e49a1a1688da15fe535ec28d77dcd21fa856f4ccd9a19c2f942`; anonymous reconstruction and both member hashes matched. The corrected light/shadow layers visibly appear, but the output remains too mechanical. This is diagnostic evidence, not a model revision or training sample. The next teacher contract explicitly separates p5 native fill from brush fill and reports the misuse in feedback; before spending on a large curriculum, test a compact incremental-revision scaffold on a small set of simple references and judge actual visual progress against the current four-turn baseline.
