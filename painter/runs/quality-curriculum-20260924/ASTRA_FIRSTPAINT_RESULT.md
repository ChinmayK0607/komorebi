# Astra first-paint SFT pilot: matched result

**Decision: do not promote step 20.** The verified 20-update SFT completed, but the same frozen 28-photo evaluation favors its public photo-SFT step-512 initializer. First-turn validity dropped from **19/28 to 14/28**, and final validity after up to two turns dropped from **19/28 to 15/28**. The 28 first-paint reference/baseline/trained images were visually inspected by the parent without blinding. The baseline also looks more recognizable overall, with occasional trained successes; this visual read is not an independent pairwise-judge win rate. The latter two retain useful subject cues; the lunchbox illustrates why validity cannot stand in for visual quality. Among shared valid outputs, the cat, bed, bus, food and sports scenes remain mixed, and no aesthetic superiority is claimed.

The baseline had eight first-turn program failures and one service failure; step 20 had twelve program failures and two service failures. Step-20 program failures include missing complete code, truncated-looking JavaScript, duplicate declarations, undefined helpers, unsupported brushes and runtime errors. Both policies encountered two second-turn HTTP 400 context failures: with an 8,192-token output request, a prompt longer than 8,192 tokens exceeds the 16,384-token server context. These are scaffold limits, not evidence about revision aesthetics. First turn is the primary outcome because this SFT supervised reference-only initial paintings. The 28 cases are a small development set, not a statistical generalization claim; the baseline itself produced 19 first-valid canvases here versus 15 in an older run, so matched controls matter.

**Next decision:** The current 39-distinct-first-paint SFT mix is not enough evidence for scaling the same recipe. An audit of the 100-scene candidate index found 11 additional *promising reference-only* teacher paintings not in this pilot, plus five promising canvas-conditioned corrections not in the 60-row export. Fifteen other promising canvas-conditioned examples were already in that export but deliberately withheld here, and 30 scenes carry a `revise` label. Thus the existing pool does not secretly contain another 61 approved reference-only paintings. Expand visually reviewed distinct-scene demonstrations and student-state corrections before another large SFT run; keep their prompt state identical to live inference. A smaller matched first-turn visual comparison can choose between checkpoints before a full two-turn rental, but do not use procedural validation loss as the selection signal. Separately fix the dynamic second-turn context budget before claiming a revision improvement. No new GPU run or recurring task was started by this decision.
