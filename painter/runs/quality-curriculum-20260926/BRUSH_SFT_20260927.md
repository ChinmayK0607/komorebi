# Conservative brush SFT campaign — 2026-09-27

**Status:** Dataset built; Linux GPU training and matched evaluation pending. No visual improvement claim yet.

The hypothesis is that one conservative LoRA pass over diverse rendered p5.brush first paints and render-conditioned revisions improves held-out painting beauty, structure, and source fidelity over the public photo-SFT step-512 initializer. The matched baseline is that initializer on the frozen 28-photo, two-turn evaluation, using the same inference settings for the trained policy.
