# Targeted actual-canvas corrections, second turn

The matched baseline for each row is the exact prior canvas on the same photo or text prompt. These are nonblind teacher-data decisions, not student results. The source bundles are public and anonymously SHA-256 verified in [the index](PUBLIC_SOURCE_INDEX.json). All runs used the pinned renderer `ad440b1aa8612e293b52fa5e68c2252926722852155eb8cd145d369a862a8a63` on finite Codex Cloud Linux CPU tasks. No GPU ran; Cloud CPU busy fraction and billed cost were not measured.

The four finite subruns used source commit `5a1a7fd8195ae7ade5a7bb060e8b17fbd614352c`, a 600-second per-program cutoff, and two worker slots each. Bus was 1/1 valid in seven seconds wall time; custard 1/1 in 128 seconds; camera/desk 2/2 in 285 seconds; ladybug/lighthouse 1/2 in 600 seconds because lighthouse timed out. Source archive SHA-256 values are in the public [source index](PUBLIC_SOURCE_INDEX.json), while exact per-program times, validity, output hashes and prior-state hashes are in the collected `run-summary.json` files. Worker count is not a measured CPU-utilization fraction.

Independent Luna-low inspected all four input/prior/new triplets for the bus, custard, camera and desk, checking file hashes against the render summaries. Its [raw audit](../../collected/quality-curriculum-20260926/luna-four-corrections-audit.json) gives both positive and negative points for each winner. Parent also inspected all four images full-size. The bus and custard are visibly more complete and faithful; the camera loses object clarity, and the desk trades stronger rendering for hair/edge artifacts.
