# Sol native-to-brush data repair pilot, 2026-09-27

**Question.** Does replacing Sol's native-p5 helper shapes with actual p5.brush marks improve the visual quality of the already-rendered 600-task teacher pool without losing the subject? This is a data repair experiment, not SFT or student evaluation. The next LoRA run must use only visually reviewed, renderer-valid targets.

**Matched baseline.** For each of eight preselected text prompts, render the exact original program and its deterministic helper translation with the same input, seed, renderer assets and timeout. Compare the two canvases side by side, including invalid and timed-out cases. Program validity and brush-use are diagnostics, not visual-quality wins.

**Scope and provenance.** The pinned [pilot plan](SOL_BRUSH_PILOT_8.json), SHA-256 `fee10e9bb8fd87f0f5640f546bef2a6a2496845a476b5c34c2be0c929b22cd52`, records every input/program/original-canvas hash and public source archive revision/hash. It spans eight categories and four Sol source bundles. Git source commit `1bf90ce3eee1514b44bfe973200910cc8a61d4de`. The [translation script](translate_sol_native.py) recognizes two exact shared helper templates: 55/75 native-only programs yield a candidate with no remaining native drawing call, and 20/75 fail closed because they contain direct native marks. The other 525 valid teacher canvases are outside this conversion. All 55 generated candidates passed Bun JavaScript syntax parsing; this is not renderer or aesthetic validation. Generated programs remain out of Git.

**Execution and result.** The finite [Codex Cloud CPU task](https://chatgpt.com/codex/cloud/tasks/task_e_6ab840d44788832b9c185e61fe4b8e0b) rendered all eight original and eight converted programs. Render wall time was 612.351 seconds for 16 canvases; worker count was two, and CPU busy fraction and Cloud dollar cost were not instrumented. Public Hugging Face dataset `CK0607/komorebi-painter-teachers` revision `957b165b3947c995d9de7faea0b6325c62d0c5bf` carries the hash-verified archive (SHA-256 `7ca008fe313e6391fbb2a25e0d381a2f1270f532c1f867bd65c9041746cd38e4`). The [collector](collect_sol_translation_pilot.py) verified the archive and each source/program/render hash and built the [local matched gallery](../../collected/quality-curriculum-20260926/rendered-cloud/sol-brush-translation-pilot-20260927/review.html). No GPU was rented and no recurring task was created.

**Parent visual decision.** Full-size inspection found **zero conversion wins in eight pairs**; the [per-scene review](SOL_BRUSH_PILOT_REVIEW.json) records the failures. p5.brush translucency weakens important subject silhouettes in every converted image, most obviously the frog, boat, stacker and fox. Thus renderer success is not data improvement. Reject the deterministic conversion for SFT and do not scale it to the 55 syntactically valid candidates. The eight originals remain correction states, not accepted teacher targets. The bounded [redo pilot](run_sol_redo_pilot_cloud.sh) will ask MiMo Flash/Pro for complete replacement programs, showing each subsequent render to the model. Only a visually reviewed image that beats the exact original may enter a LoRA mix. Compare any LoRA continuation against its exact initializer on held-out text and photo scenes before expanding.
