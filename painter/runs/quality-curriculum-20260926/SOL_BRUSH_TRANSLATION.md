# Sol native-to-brush data repair pilot, 2026-09-27

**Question.** Does replacing Sol's native-p5 helper shapes with actual p5.brush marks improve the visual quality of the already-rendered 600-task teacher pool without losing the subject? This is a data repair experiment, not SFT or student evaluation. The next LoRA run must use only visually reviewed, renderer-valid targets.

**Matched baseline.** For each of eight preselected text prompts, render the exact original program and its deterministic helper translation with the same input, seed, renderer assets and timeout. Compare the two canvases side by side, including invalid and timed-out cases. Program validity and brush-use are diagnostics, not visual-quality wins.

**Scope and provenance.** The pinned [pilot plan](SOL_BRUSH_PILOT_8.json), SHA-256 `fee10e9bb8fd87f0f5640f546bef2a6a2496845a476b5c34c2be0c929b22cd52`, records every input/program/original-canvas hash and public source archive revision/hash. It spans eight categories and four Sol source bundles. Git source commit `1bf90ce3eee1514b44bfe973200910cc8a61d4de`. The [translation script](translate_sol_native.py) recognizes two exact shared helper templates: 55/75 native-only programs yield a candidate with no remaining native drawing call, and 20/75 fail closed because they contain direct native marks. The other 525 valid teacher canvases are outside this conversion. All 55 generated candidates passed Bun JavaScript syntax parsing; this is not renderer or aesthetic validation. Generated programs remain out of Git.

**Execution.** A finite Codex Cloud CPU task was submitted to render the eight matched pairs using [the pinned runner](render_sol_translation_pilot_cloud.py) and upload hash-verified public evidence. No GPU was rented and no recurring task was created. Cloud task: https://chatgpt.com/codex/tasks/task_e_6ab840d44788832b9c185e61fe4b8e0b . The local [collector](collect_sol_translation_pilot.py) will verify the archive and every canvas/program hash and build a comparison gallery.

**Decision after collection.** Scale the deterministic conversion only if the images actually look better at comparable subject fidelity. If not, keep the original as a correction state and obtain a new render-inspect-revise demonstration, favoring MiMo Flash/Pro brush-native teachers. Do not admit any of the 600 originals or translations to SFT solely because they render. After enough distinct reviewed positives exist, train a short LoRA continuation from the public step-512 student and compare it to that initializer on the same held-out prompts and photos before expanding. Spend, CPU utilization and visual results are not yet measured.
