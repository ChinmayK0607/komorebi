# Structured-flow supervised warmup and RL pilot

The hypothesis is that demonstrations of coherent painting construction—silhouette, value masses, connected parts, restrained details, and inspection-driven revision—help the selected painter preserve spatial structure and brush character. The user selected Flash after inspecting the completed matched ablation. Code supervision teaches actual painting actions; code formatting and comment names earn no reward.

The initializer is public Flash step12: `CK0607/qwen3.8-27b-brush-painting`, revision `1227a2427a8ae16014d2fdca4d1adb6855d3fa1c`, prefix `rl-judge-matched-20261004-flash/step_12`, adapter SHA-256 `c70c47ec0d6d7172b3bc25c4f54178919cf7c079cd9652fff3bc76db9e1eca79`. Both SFT and subsequent RL use fresh optimizers. The base is `Qwen/Qwen3.8-27B` at `1d4bf0f2ff6012fd82039f2fa52739d0dd7c60c0`; Prime is pinned to `26b3131d2716a4f8210b165df584b83b4bc54f61`.

The matched improvement baseline is a fresh pretraining evaluation of Flash step12 on the same new heldout briefs, system instructions, decoding settings, renderer, seed, and turn limit as the trained evaluation. The previous ablation gallery is not this matched baseline. Public SFT512 (revision `adf687e5b321514eda7be6eab050434fdc8e44ff`, prefix `photo-curriculum-sft-20260922-balanced/step_512`, SHA-256 `bea72b066986faa1b92b9dc539c710093181ee916b99323e2b2498f318ac1740`) is the fixed per-brief reward opponent, not the new policy initializer.

Prepared scope: 240 training and 60 heldout brief variants from 20 subject families, split by family before variation. Levels cover isolated forms, connected objects, overlaps/support relationships, then scenes. The bounded first run uses 32 training and 16 heldout briefs from levels 1–2. The remaining 208/44 briefs remain prepared proposals, not completed anchors or consumed training data. Later levels retain earlier-level replay. Sixteen authored demonstration candidates provide two complete programs each. Only actually rendered and reviewed actions are trainable; final revisions must improve their incoming block-in. Heldout families must not enter supervised warmup. Earlier programs and their actual canvases are user context; only the next assistant action receives loss. Exact processor masks and absence of target truncation must be checked on Linux.

Proposed first run: four gentle supervised updates at learning rate `1e-6`, then eight RL updates with checkpoints at four and eight, batch 16, group 4, 32 in-flight episodes, one trainer and one inference GPU, and RL learning rate `1e-6`. Initial episodes have at most three turns. A finite controller reserves time for evaluation, public hash-verified checkpoints/evidence, and exact node release. Actual admitted/consumed counts and completed optimizer updates will be recorded separately.

The MiMo Flash Gateway judge uses the existing generic aesthetic pairwise protocol, requested medium effort, joint side schema, and unchanged rubric. The judge sees the original painting brief and images. Flow guidance reaches the policy and SFT context, without being appended to the judge's subject brief. No extra aesthetic/code reward and no new signed turn-credit estimator are introduced in this pilot. Terminal GRPO therefore still has coarse turn credit; this run tests supervised flow first.
